# 💬 Chatnova

Chatnova is a full-stack language exchange platform that helps users connect with people worldwide through real-time messaging and video calls. It enables users to discover language partners, build friendships, and practice languages in an interactive environment.

## ✨ Features

- 🔐 JWT Authentication
- 👤 User Profiles & Onboarding
- 🌍 Language Partner Discovery
- 🤝 Friend Requests
- 💬 Real-Time Chat
- 🔔 Live Notifications
- 🎨 Responsive UI with Multiple Themes

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, DaisyUI, Axios

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs

**APIs:** Stream Chat SDK & Stream Video SDK

## 🚀 Getting Started

```bash
# Install dependencies
cd backend && npm install
cd ../frontend && npm install

# Start backend
cd backend
npm run dev

# Start frontend
cd frontend
npm run dev
```

## 🔑 Environment Variables

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET_KEY=your_secret_key
STREAM_API_KEY=your_stream_api_key
STREAM_API_SECRET=your_stream_api_secret
```
